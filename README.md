# 🛍️ Fernanda Store - Loja Online Premium

Bem-vindo ao repositório da **Loja Fernanda Store** - Uma loja online moderna, responsiva e profissional de moda e roupas!

## ✨ Características Principais

✅ **Design Moderno e Responsivo**
- Interface intuitiva e atraente
- Totalmente responsivo (mobile, tablet, desktop)
- Animações suaves e profissionais

✅ **Galeria de Imagens e Vídeos**
- Galeria com efeito lightbox
- Vídeos integrados do YouTube
- Hero banner com vídeo de fundo
- Imagens de alta qualidade dos produtos

✅ **Funcionalidades de E-commerce**
- Catálogo de produtos com imagens
- Filtro por categoria
- Busca de produtos em tempo real
- Carrinho de compras funcional
- Modal detalhado de produtos
- Seletor de tamanhos e quantidade
- Integração com WhatsApp para checkout

✅ **Recursos Extras**
- Depoimentos de clientes com fotos
- Seção de vídeos em destaque
- Newsletter para contato
- Links para redes sociais (Instagram, TikTok, Facebook, YouTube)
- Botão WhatsApp flutuante
- Loader animado na inicialização

## 🎬 Seções do Site

1. **Header** - Logo, busca e carrinho
2. **Hero Banner** - Vídeo de fundo com call-to-action
3. **Destaques** - Cards de categorias com gradientes
4. **Galeria** - Fotos de looks com efeito lightbox
5. **Catálogo** - Grade de produtos com imagens
6. **Vídeos** - Seção com vídeos do YouTube
7. **Depoimentos** - Avaliações com fotos de clientes
8. **Footer** - Informações, redes sociais e newsletter

## 🔧 Customização

Para customizar:

1. **Cores:** Edite as variáveis CSS em `:root` no `style.css`
2. **Produtos:** Modifique o array `produtos` em `script.js`
3. **Textos:** Edite o HTML em `index.html`
4. **WhatsApp:** Atualize o número em `script.js` e `index.html`
